# DataLens 🔍 — 本地 CSV 数据分析与清洗工具

**DataLens** 是一款轻量级、纯浏览器端的 CSV 数据分析与清洗工具。所有数据处理均在本地完成，**不上传任何数据到服务器**。

## 使用场景

- 快速查看 CSV 文件的基本信息和结构
- 自动检测数据质量问题（缺失值、重复行、类型错误）
- 执行常见数据清洗操作（去重、填充缺失值、类型转换）
- 生成可视化图表辅助理解数据分布
- 导出清洗后的数据和分析报告

适合数据分析初学者、学生、开发者在日常工作中快速处理 CSV 数据。

## 核心功能

| 功能 | 说明 |
|------|------|
| CSV 导入 | 点击上传 / 拖拽上传，支持 UTF-8 编码 |
| 数据预览 | 分页浏览、字段排序、全文搜索 |
| 数据质量分析 | 缺失值统计、重复检测、类型推断、数值统计 |
| 数据质量评分 | 透明评分机制，清晰展示扣分项 |
| 数据清洗 | 删除重复行、处理缺失值（填充/删除）、类型转换 |
| Undo 撤销 | 支持多步撤销操作历史 |
| 数据可视化 | 折线图、柱状图、饼图、数值分布图，自动推荐图表类型 |
| 数据导出 | 导出清洗后 CSV、导出 JSON 分析报告 |
| 纯本地处理 | 所有数据在浏览器本地处理，不上传服务器 |

## 数据处理流程

```
拖入 CSV
    ↓
Papa Parse 解析 → 字段自动识别
    ↓
数据预览（分页 / 排序 / 搜索）
    ↓
数据质量分析（主线程 / Web Worker）
    ├── 缺失值统计
    ├── 重复行检测
    ├── 类型推断
    ├── 数值统计
    └── 质量评分
    ↓
数据清洗
    ├── 删除重复行
    ├── 填充缺失值（均值/中位数/0/Unknown）
    ├── 类型转换（数字/字符串/日期）
    └── Undo 撤销
    ↓
数据可视化
    ├── 折线图（日期+数值）
    ├── 柱状图（分类+数值）
    ├── 饼图
    └── 分布直方图
    ↓
导出
    ├── CSV（清洗后数据）
    └── JSON 分析报告
```

## 数据质量评分算法

评分机制完全透明，在 UI 中展示每个扣分项：

- **基础分**: 100
- **缺失值扣分**: 最多 -50（基于缺失率）
- **重复行扣分**: 最多 -30（基于重复率）
- **无效日期扣分**: 最多 -20
- **最终得分**: max(0, 100 - 合计扣分)

## 清洗机制

所有清洗操作均基于操作历史栈：

1. 点击清洗按钮时，系统**预览**变更效果（受影响行数、填充数量等）
2. 点击"应用"后，当前数据状态被保存到 `history` 栈
3. 原始数据始终保留在 `originalRows` 中
4. Undo 操作回退历史栈，恢复前一步数据

## Undo 机制

- 采用**快照历史栈**：每次 Apply 清洗操作时，将当前数据深拷贝保存
- `historyIndex` 指针控制当前状态
- Undo 时 historyIndex 回退，恢复对应快照
- 新的操作会截断后续历史

## Web Worker 设计

当数据集行数超过 **5,000** 时，数据分析自动启用 Web Worker：

```
Main Thread               Web Worker
    │                          │
    ├── CSV 解析                │
    ├── 用户交互                 │
    │                          │
    ├── postMessage(rows) ────> │
    │                          ├── 类型检测
    │                          ├── 缺失值统计
    │                          ├── 重复行检测
    │                          ├── 数值统计
    │                          └── 质量评分
    │                          │
    │ <──── postMessage(report) │
    │                          │
    └── 更新 UI                 │
```

- 小数据集（< 5,000 行）走主线程同步执行，无额外开销
- 大数据集自动切换 Worker，不阻塞 UI

## 隐私设计

- **所有数据处理在浏览器本地完成**
- 没有后端服务器
- 没有数据上传 API
- 不收集用户数据
- 不依赖第三方数据分析服务
- 使用 IndexedDB 持久化数据（仅在本地浏览器存储）
- UI 顶部持续显示隐私声明

## 性能测试

| 数据量 | 解析时间 | 分析时间 | 内存占用 |
|--------|----------|----------|----------|
| 10,000 行 | <0.5s | <1s | ~15MB |
| 50,000 行 | ~1s | ~2s | ~60MB |
| 100,000 行 | ~2s | ~4s | ~120MB |

性能优化策略：
- Web Worker 将大数据分析移至后台线程
- 预览表采用**分页**（每页 50 行），避免渲染大量 DOM
- 图表渲染限制为 5,000 个数据点
- 类型推断采样前 1,000 行
- 唯一值统计采样前 5,000 行
- 按需加载：所有视图页面使用 Vue 动态 `import()` 懒加载，首页只加载 ~20kB 核心代码
- 代码分包：ECharts 和 Vue 框架独立 chunk 输出，未访问图表页时不加载 ECharts
- 搜索防抖（300ms），避免大数据量下每次按键触发全量搜索

## 项目难点

1. **大数据量下的 UI 性能**：10 万行数据若全部渲染会导致页面卡死。通过分页 + Web Worker + 采样统计三重策略解决。
2. **类型推断的准确性**：字符串可能"看起来像数字"，日期格式变化多端。算法通过多数表决和多种正则匹配来提高准确性。
3. **清洗操作的可撤销**：采用快照模式而非操作日志模式，简化实现但内存开销较大。适合 CSV 数据的典型使用模式（操作次数少、数据量中等）。
4. **Web Worker 模块化**：Vite 的 worker import 语法与原生 Worker 不同，需要正确配置 `type: 'module'`。
5. **图表自动推荐**：根据字段类型（日期、数值、字符串）自动推荐合适的图表类型，减少用户学习成本。
